Data import and sources

Every observation keeps its origin: NASA live NRT NASA archive import synthetic demo. Demo data never mixes with NASA data.

1 · Live NASA retrieval (NRT)

Fetches MODIS, VIIRS S-NPP, NOAA-20 and NOAA-21 for the Punjab + Haryana study area using the server-side FIRMS key. Each source is recorded separately, so a failed source is never shown as zero detections.

2 · Import a NASA FIRMS archive export

Get a CSV (or JSON) from FIRMS Download (archive requests may need an Earthdata login or email delivery). Request MODIS and VIIRS separately for Punjab and Haryana, then upload them here. The app cannot verify that a file really came from NASA; it records it as “NASA archive import” as you supplied it. Shapefiles are not supported yet.

Coverage tells the calendar which days were requested, so days with no detections show as true zero instead of “no data”. If you leave the dates blank, coverage is only assumed (first to last detection date): those days are never shown as confirmed zero and are excluded from anomaly baselines. The extent is required. Coverage applies only to regions fully inside the extent you declare and is never inferred from where detections appear. Regions are approximate bounding boxes, not administrative boundaries.

Generated by a script for testing the interface. Not NASA data, not real fires.
